# The Green Energy & e-Waste Hub
**AFS Global STEM Changemakers Capstone Project**

## Sustainable Development Goals (SDGs)
- **SDG 7:** Affordable and Clean Energy
- **SDG 12:** Responsible Consumption and Production

## Features
- **Impact Calculator:** Real-time CO2 and precious metal recovery estimation.
- **Locator Directory:** Drop-off recycling locations for batteries, electronics, and solar tech.
- **DIY Guides:** Step-by-step clean energy upcycling projects.
- **Community Forum:** User authentication and comment board.

## How to Host on GitHub Pages
1. Push `index.html` to your GitHub repository.
2. Go to **Settings > Pages**.
3. Select the `main` branch and click **Save**.
